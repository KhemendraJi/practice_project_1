#### My First Portfolio Website - Cynthia Ugwu Replica

#### About the Project

Hello! I'm a beginner web developer, and this is my first web development project. I recreated the portfolio website of Cynthia Ugwu (cynthiaugwu.com) to learn and practice web development. It took me two full days to build this, and I learned a lot during the process. I didn’t want to just copy and paste code, so I made sure to understand each step while building it. This project is a big milestone for me, and I’m really excited to share it!

What I Learned

This project was like a crash course in web development for me. Here’s what I picked up along the way:

- **HTML & CSS:** I learned how to structure a webpage and style it to match the original site.
- **JavaScript:** I used it to add cool features like a custom cursor and smooth scrolling.
- **Locomotive Scroll:** I figured out how to add smooth scrolling with help from a YouTube tutorial by Sheriyans Coding School.
- **GSAP:** I played around with animations to make the website feel lively.
- **Custom Cursor:** I built a custom cursor effect, which was challenging but fun.
- **Debugging:** I spent a lot of time fixing small issues and learning why things didn’t work at first.

#### How I Did It

I started by checking out the original website (cynthiaugwu.com) to understand its design and features. Then, I try to do it myself and followed a tutorial from Sheriyans Coding School on YouTube on parts which are new to me like to learn how to use Locomotive Scroll and create a custom cursor. I made sure to write the code myself and understand each part instead of just copying it. It was a lot of work, but seeing the final result made it worth it!

#### Challenges I Faced

Being new to coding, I hit a few roadblocks:

- Getting Locomotive Scroll to work smoothly required a lot of tweaking.
- Matching the exact look of the original website was harder than I expected.
- The custom cursor didn’t always behave well on different screen sizes, which was tricky to fix.

Solving these problems taught me patience and how to search for solutions online.

You can check out my code here: https://github.com/KhemendraJi/practice_project_1
